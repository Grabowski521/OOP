# Классы Product и Category

Этот модуль содержит два основных класса: `Product` и `Category`. Класс `Product` представляет отдельный товар, а класс `Category` представляет категорию товаров, в которой могут быть добавлены и удалены продукты.

## Класс Product

Класс `Product` используется для создания объектов, представляющих товары. У каждого товара есть название, описание, цена и количество.

### Атрибуты:
- `name`: Название товара (строка).
- `description`: Описание товара (строка).
- `price`: Цена товара (число с плавающей точкой).
- `quantity`: Количество товара на складе (целое число).

### Методы:
- `__str__()`: Возвращает строковое представление объекта `Product`.

## Класс Category

Класс `Category` используется для создания объектов, представляющих категории товаров. Каждая категория имеет название, описание и список товаров.

### Атрибуты:
- `name`: Название категории (строка).
- `description`: Описание категории (строка).
- `products`: Список товаров, принадлежащих категории (список объектов `Product`).

### Статические атрибуты:
- `total_categories`: Общее количество категорий (целое число).
- `total_products`: Общее количество товаров во всех категориях (целое число).

### Методы:
- `add_product(product: Product)`: Добавляет товар в категорию. Если переданный объект не является экземпляром класса `Product`, выбрасывается исключение `ValueError`.
- `remove_product(product: Product)`: Удаляет товар из категории. Если товар не найден в категории, выбрасывается исключение `ValueError`.
- `__str__()`: Возвращает строковое представление объекта `Category`.
